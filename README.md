# Python Mini Projects Suite 🚀

A collection of lightweight and practical Python command-line tools featuring a voice assistant, BMI calculator, and a real-time weather app.

---

## 🛠️ Included Projects & Files

### 1. Voice Assistant (`voice_assistant.py`)
* **Description:** A basic speech-enabled script that uses text-to-speech feedback and voice recognition.
* **Dependencies:** `pyttsx3`, `SpeechRecognition`

### 2. BMI Calculator (`bmi_calculator.py`)
* **Description:** A quick utility tool that calculates Body Mass Index based on user weight (kg) and height (m) and categorizes the result (Underweight, Normal, Overweight, Obese)[cite: 2].

### 3. Weather App (`weather_app.py`)
* **Description:** A command-line weather tool that fetches real-time meteorological data using the OpenWeatherMap API[cite: 1].
* **Features:** 
  * CLI argument support for location queries[cite: 1].
  * Optional extended details flag (`-e` / `--extended`) to check humidity and other metrics[cite: 1].
  * Secure environment variable configuration (`OPENWEATHER_API_KEY`)[cite: 1].
